## Ask WPB versus Contact the Team

Ask is not currently one concierge system. In the audited baseline it is visible on **4/10 desktop routes** (map, floorplans, Rosewood, South Flagler) and **0/10 mobile routes**. Contact is a separate generic inquiry path where the legacy shell renders it. Bespoke project and comparison shells expose different navigation/actions.

`src/main.ts`, `initBuyerAssistant` / `appendChatMessage` / `answerBuyerAssistantQuestion` (around lines 3552–3620 at production SHA), implements deterministic local keyword matching against public project/corridor information. It returns canned strings containing `/inquire/`, project and library routes. `appendChatMessage` assigns those strings to a paragraph's `textContent`, so they are not clickable or context-preserving handoff buttons. No live availability lookup or generative API is implemented by this component. The audit opened the panel without submitting a question; this handoff diagnosis is source-confirmed, not a claimed live AI test.

All four observed desktop panels failed to restore focus to the launcher after the collector pressed Escape. The current initializer implements click-to-toggle and click-to-close and focuses the question input on open; it contains no Escape/focus-return handler. Treat this as required keyboard acceptance for the replacement, not as proof that the complete site has no other keyboard behaviors.

The inline project-form mismatch is independently confirmed by `renderProjectInquiryForm` around lines 8788–8814: the form reuses `rules.primaryCtaLabel` for its heading and submit button while storing the separately selected `rules.inquiryInterest`. On the live Olara/Maison forms those values are View Floorplans versus Request current availability.

## Technical observations linked to the inventory

All ten raw production documents contain relative `og:image` and `twitter:image` values. Legacy hydration makes nine routes' values absolute HTTPS, while the independent comparison route remains relative. Maison also selects a different valid-looking asset path between raw HTML and hydration; choose the approved route image consistently during the shared-helper fix rather than assuming this is merely a prefix operation. Actual image availability must be regression-tested before changing selection.

The central raw writer in `research/scripts/prerender-static-routes.mjs` interpolates `route.ogImage` directly into both image metas (around lines 175 and 179). Runtime/template consumers must share the same public absolute-URL normalization. A browser-only fix is insufficient for the raw-document defect.

First-party application JS body sizes and duplicate-media footprints are reported in the main Batch 6 document. Their interpretation is deliberately separate from measured user conversion, Core Web Vitals or total network transfer.
