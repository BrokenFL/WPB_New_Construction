# Post-release measurement plan

This is a plan for an approved future release, not an activation or an uplift claim. No analytics infrastructure was added or enabled in this milestone. Search Console authentication was unavailable; the repository's August 5–September 1 baseline is historical. Search clicks, page views, form starts and qualified inquiries are different outcomes.

## Establish a usable baseline

After Brooke separately approves release and analytics access is available, record the deployment SHA/date and collect comparable 28-day windows before and after it. Segment mobile/desktop and search/direct/referral traffic; annotate publication volume and major project news. At this site's observed search volume, report raw counts and denominators alongside rates. Do not interpret a small percentage swing as a proven design effect.

Use only the existing consented analytics implementation. Verify consent and event delivery against the existing analytics contract before using a report. A rejected-consent visit is not an observable zero-engagement visit. Never join personal inquiry fields into browser analytics or send query strings, messages, names, emails or phone numbers. If reports or permitted returning-user dimensions are unavailable, mark the metric unavailable; do not add fingerprinting or activate parked transport work.

## Review cadence and decisions

Within 48 hours of an approved release, verify routes, consent, saved-lead receipts and real Maps independently of CI. After 14 days, look for technical failures and obvious journey drop-offs without declaring uplift. At 28 days, compare the windows and review a permitted sample of qualified inquiries. Extend observation if counts are too small or a major launch/news event makes the windows incomparable. This cadence is a recommendation; no automation was scheduled.

Keep the hybrid homepage if the data supports meaningful news-to-research use without hurting building discovery. Consider simplifying the repeated lower-page discovery prompts if task observation and journey data agree that they add friction. Consider further form reduction only after checking which fields are useful in actual qualification. Any future experiment should have a clear hypothesis, stable event definition and release approval; these internal design scores are not evidence of conversion gains.
