# Content Image Resolution Policy

Use the most specific trustworthy visual available. A building story should show the building, not a generic corridor image.

## Priority Order

1. Explicit story or article image override.
2. Related project image when the story clearly corresponds to one building.
3. Related project hero or gallery image.
4. Corridor-specific editorial image.
5. General West Palm Beach geography editorial image.
6. Placeholder only when no valid asset exists.

## Rules

- Exact building imagery beats corridor imagery.
- Manually curated or user-provided project imagery remains first priority for public project pages.
- Approved imported developer-site images may support project galleries and project-specific cards.
- Imported images marked `needs_review`, `rejected`, or `archived` must never render publicly.
- Exact attraction imagery beats generic Downtown imagery for attraction/lifestyle stories.
- Corridor imagery is fallback context only.
- Rosewood renderings are project-specific and must not be used as generic North Flagler imagery.
- Kravis Center imagery is Downtown attraction context, not building imagery.
- NORA imagery is for NORA / North Downtown growth context, not unrelated Downtown stories.
- South Flagler has its own corridor images; do not use the North Flagler waterfront image for South Flagler when those assets exist.
- Use `Editorial visual`, `Downtown attraction`, or `User-provided project rendering` style captions. Do not label a rendering official unless the source is confirmed.
- Keep corridor and editorial image labels outside the image frame. The image itself should remain clean; captions or metadata belong below or beside the image.
