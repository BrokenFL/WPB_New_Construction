Use a separate Maps JavaScript API key with billing/API enabled, API restriction to Maps JavaScript API and website/HTTP-referrer restriction `http://127.0.0.1:4173/*`. Human restriction review is required; this variable is not automated proof of Cloud settings. Do not put keys in chat or commits, expose deployment credentials, or relax the production key.

The secret is supplied only to the approved review build. Each PR's required keyed full suite, preflight and actual map checks must pass on its reviewed candidate. Credential-free fallback tests do not replace it. The aggregate workflow gate cannot pass if either job fails or is skipped. No branch-protection administration change was made.
