# Codebase Memory MCP

This repo uses `codebase-memory-mcp` as a local structural memory layer for Codex.

Before broad repo exploration or changes to routing, generated data, compare data, project slugs or aliases, build scripts, or QA and deploy workflows:

- use the codebase-memory MCP tools first
- get an architecture overview
- locate the relevant routes, pages, data generators, and dependencies
- trace impact paths and generated-vs-source-of-truth files
- confirm with direct reads, grep/search, tests, and build checks

The graph is a map, not the territory. Do not rely on it alone.
