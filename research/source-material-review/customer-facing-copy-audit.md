# Customer-Facing Copy Audit

## Pages Reviewed
- Home, map, compare, updates, Market Notes index, Market Notes articles, inquiry, corridor pages, project pages, answers, methodology, and floorplans.

## Major Copy Changes
- Reframed updates as source-linked buyer background, not a raw publishing feed.
- Replaced internal workflow language with buyer-facing verification language.
- Changed article and comparison CTAs toward current availability, floor-plan packet review, and private building comparison.
- Added developer/project image disclaimer language for project pages and footer media context.
- Updated Market Notes language to focus on source-backed buyer guidance and current verification before making a decision.

## Phrases Removed
- source-aware context
- buyer reliance
- stale numbers
- needs_review in shipped sample data
- manual approval for developer-site images
- internal note language on buyer pages

## Before / After Examples
- Before: "source-aware context and practical availability checks."
- After: "source-backed buyer guidance and practical availability checks."
- Before: "Older updates are preserved for context and should be verified before buyer reliance."
- After: "Older updates are useful background. For current pricing, availability, and delivery timing, ask Brooke to verify the latest details."
- Before: "Raw feed results stay in review until approved."
- After: "We keep external reporting linked to its source so buyers can separate background news from current decision details."
- Before: "build a shortlist around stale numbers."
- After: "build a shortlist around older public numbers."

## Remaining Copy Concerns
- Some archived project document HTML files contain third-party source markup and should not be treated as authored site copy.
- A future branch should refresh generated answer data from source scripts after any broader fact-model changes.
