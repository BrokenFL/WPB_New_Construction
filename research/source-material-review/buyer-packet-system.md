# Buyer Packet System

## Reusable Packet Types

1. `North Flagler Comparison`
   - Olara
   - Ritz-Carlton WPB
   - Shorecrest
   - Alba
   - Mandarin Oriental

2. `Downtown And NORA`
   - Mr. C
   - NORA House
   - catalog-only downtown projects

3. `South Flagler Benchmark`
   - South Flagler House
   - future South Flagler catalog projects

4. `Single Project Brief`
   - One project per packet
   - facts, team, images, floorplans, location, advisor notes

## Required Sections

- Cover with project/corridor name.
- Why this project matters.
- Map/corridor context.
- Snapshot facts.
- Floorplan access and gaps.
- Image/source status.
- Buyer questions to verify before offer.
- Advisor contact block.

## Canva / Presentation Direction

- Use authorized project images only for public-facing versions.
- Use pending projects only in internal drafts or with generated/editorial placeholders.
- Keep visual style restrained, luxury, editorial, and information-dense.
- Avoid generic real-estate hype; focus on comparison clarity and buyer confidence.
