# Asset Bloat Cleanup Plan

## Summary
Duplicate inventory is generated by `npm run assets:duplicates` in `research/source-material-review/asset-duplicate-inventory.json`. The public site also now has imported developer-image variants, so the cleanup rule is conservative: keep every placed public image and only remove exact duplicate aliases when the existing cleanup script marks them safe.

## Duplicate Groups
- Exact public/research mirrors are tracked in the duplicate inventory.
- Imported developer image variants are classified by placement status in `research/imported-project-images/importedProjectImages.json`.
- Orphaned imported files created during interrupted imports should remain unreferenced unless a later cleanup script explicitly archives them.

## Canonical Copy
- Public canonical: files referenced by `src/main.ts`, `src/data/approvedImportedProjectImages.json`, `public/data/*.json`, or project page media.
- Research canonical: original captures, source inventories, and review JSON under `research/`.
- Build output: `dist/` is disposable after deploy and can be regenerated from source.

## Public vs Research Mirror
- Do not remove public project media when it is referenced by page code, public data, or placed imported-image metadata.
- Do not remove research originals that preserve source traceability.
- Prefer removing generated `dist/` duplicates and exact public aliases only through `npm run assets:cleanup-approved`.

## Safe Archive Targets
- Exact duplicate public aliases already identified by the cleanup script.
- Older generated QA/build outputs.
- Imported orphan files not present in `importedProjectImages.json`, after confirming no source reference exists.

## Expected Byte Savings
- `npm run assets:cleanup-approved` removed 5 files/paths and 439.4 MB, including disposable `dist`, `.playwright-cli`, and duplicate Olara floorplan aliases.
- Post-cleanup duplicate inventory dropped from 524,855,964 duplicate extra bytes to 469,237,692 duplicate extra bytes.
- Public-only duplicate extra bytes dropped from 55,519,017 to 2,033,973.

## Files Not Safe To Remove
- Any file referenced by `src/data/approvedImportedProjectImages.json`.
- Any `public/projects/*/media/user-provided-*` asset.
- Any project logo in `public/projects/*/media/logo.*`.
- Research source captures needed to preserve project image source metadata.
