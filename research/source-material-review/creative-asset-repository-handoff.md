# Creative Asset Repository Handoff

Creative assets are mirrored to a separate GitHub repository so the site repo can stay focused on the deployable app.

## Repository

- Owner: `BrokenFL`
- Repository: `WPB_New_Construction_Assets`
- Intended visibility: private asset workspace

## What Belongs There

- `research/asset-library/`
- Published project media from `public/projects/`
- Team logos from `public/team-logos/`
- Hero, map, and concept assets from `public/hero/`, `public/maps/`, and `public/concepts/`

## Site Publishing Rule

An asset can live in the asset repository before it is approved for the live site. Only publish it into `public/` when it is user-provided, licensed, approved, or already cleared for site use.

For developer, architect, designer, and landscape images or logos:

- Match the asset to the project-team role before publishing.
- Prefer project-specific approved assets over generic placeholders.
- Do not publish assets marked `rights review required` without explicit approval.
- Do not link the asset back to the project sponsor or designer website from the public site.
